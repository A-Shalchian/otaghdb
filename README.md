# OtaghDB

Your room as a searchable database. Photograph your things, file them by room, spot and container, and find them again.

The build plan is in [PLAN.md](PLAN.md).

## Run it

```bash
pnpm install
```

```bash
pnpm dev
```

The app runs at http://localhost:3100. The database and photos are stored in `data/`, which is not committed.
